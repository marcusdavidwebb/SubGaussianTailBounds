# Historical supplement

[`supplementary.tex`](../supplementary.tex) and its
[`supplementary.pdf`](../supplementary.pdf) are temporary historical documents,
pending the maintainer's later deletion. Their mathematical text is preserved;
they are not maintained proof submissions or documents to update when the Lean
formalization changes. The current project targets the immutable
[`MainTheoremStatement.lean`](../MainTheoremStatement.lean).

The natural-language statement of Theorem S1.1 remains in the
[README](../README.md#theorem-statement). Its proof is not copied into active
documentation. Substantial credit, preceding human mathematics, model
identities, tool roles and Marcus Webb's responsibility survive independently
in [the contribution history](../CONTRIBUTIONS.md) and
[provenance](PROVENANCE.md).

The historical source's introductory claim that the paper is on arXiv has no
verified public identifier here. The accompanying paper is described as **in
preparation**, by Marcus Webb and Morgan Lynch-Davies. This notice does not
invent missing paper content, a public version or a repository release.

If a deliberate historical document edit is necessary, use the existing
[document build instructions](BUILDING.md) and check citations, references,
box warnings and changed pages. Building the historical document does not
verify the canonical Lean targets. The optional manual Supplement build
workflow is separate from required Lean CI. Installing the revised required
gate on the trusted base is described in [CI policy](CI.md).
